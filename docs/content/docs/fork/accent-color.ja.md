アップストリームの Hextra は、3 つの HSL 変数（`--primary-hue`、`--primary-saturation`、`--primary-lightness`）からプライマリカラーを生成します。このフォークではこれを、`oklch` で定義された本格的な **11 段階のアクセントパレット**に置き換えました。1 つの色相からすべてを派生させるのではなく、各シェードを完全にコントロールできます。

<!--more-->

## なぜ色相ではなくパレットなのか？

単一の色相・彩度ペアから 10 段階のシェードを派生させると、中間トーンが濁り、両端でコントラストが不足しがちです。手作業（またはジェネレータ）で選んだパレットなら各シェードを個別に調整できます。さらに `oklch` は色相をまたいでも知覚的な明度を一定に保つため、シェード `500` のオレンジのアクセントと青のアクセントが同じ明るさに*見えます*。

## アクセントカラーの上書き

サイトの `assets/css/custom.css` に 11 個の変数を追加します（このファイルは Hextra が自動的に読み込みます）：

```css {filename="assets/css/custom.css"}
:root {
  --color-accent-color-50: oklch(0.977 0.013 236.62);
  --color-accent-color-100: oklch(0.951 0.026 236.824);
  --color-accent-color-200: oklch(0.901 0.058 230.902);
  --color-accent-color-300: oklch(0.828 0.111 230.318);
  --color-accent-color-400: oklch(0.746 0.16 232.661);
  --color-accent-color-500: oklch(0.685 0.169 237.323);
  --color-accent-color-600: oklch(0.588 0.158 241.966);
  --color-accent-color-700: oklch(0.5 0.134 242.749);
  --color-accent-color-800: oklch(0.443 0.11 240.79);
  --color-accent-color-900: oklch(0.391 0.09 240.876);
  --color-accent-color-950: oklch(0.293 0.066 243.157);
}
```

テーマの再ビルドは不要です。これらはランタイムの CSS 変数なので、`custom.css` で上書きするだけで、アクセントカラーを使うすべての要素のスタイルが一度に切り替わります。

## UI Colors でパレットを生成する

11 個のシェード値を得るには、無料の Tailwind スタイルのパレットジェネレータである [uicolors.app](https://uicolors.app) の利用をおすすめします：

{{% steps %}}

### ブランドカラーを入力する

[uicolors.app](https://uicolors.app/create) を開き、上部の入力欄にベースカラーを入力または貼り付けます（16 進数、例：`#0ea5e9`）。シャッフルボタンで探索することもできます。ジェネレータは入力した色をアンカーとなるシェードとして扱い、その周囲に `50`〜`950` の完全なランプを構築します。

### ランプを微調整する

ページに表示されるサンプル UI カードでパレットをプレビューします。中間シェード（`500`/`600`）がブランドカラーに一致し、両端が実用的なまま（明るい `50`/`100` の背景、暗い `900`/`950` のサーフェス）になるまで、色相・彩度・明度のカーブを調整できます。

### シェードをエクスポートする

**Export** をクリックし、CSS で使いやすい形式を選びます。ここではそのまま使える形式が 2 つあります：

- **Tailwind (OKLCH)** — テーマのネイティブ形式に一致するため推奨
- **Tailwind (HEX)** — こちらでも問題ありません。有効な CSS カラー値ならどれでも動作します

### 値を `custom.css` に対応付ける

エクスポートした各シェードを、対応する `--color-accent-color-*` 変数にコピーします。`50` は `50` に、`100` は `100` に、という具合です：

```css {filename="assets/css/custom.css"}
:root {
  /* "tangerine" palette from uicolors.app */
  --color-accent-color-50: oklch(0.98 0.016 73.684);
  --color-accent-color-100: oklch(0.954 0.038 75.164);
  --color-accent-color-200: oklch(0.901 0.076 70.697);
  --color-accent-color-300: oklch(0.837 0.128 66.29);
  --color-accent-color-400: oklch(0.75 0.183 55.934);
  --color-accent-color-500: oklch(0.705 0.213 47.604);
  --color-accent-color-600: oklch(0.646 0.222 41.116);
  --color-accent-color-700: oklch(0.553 0.195 38.402);
  --color-accent-color-800: oklch(0.47 0.157 37.304);
  --color-accent-color-900: oklch(0.408 0.123 38.172);
  --color-accent-color-950: oklch(0.266 0.079 36.259);
}
```

サイトをリロードすると、リンク、タブ、ハイライト、その他すべてのアクセント要素が即座に新しいパレットを反映します。

## 内部の仕組み

`assets/css/styles.css` には 2 つのレイヤーがあります：

1. **生のパレット** — `--color-accent-color-50` … `--color-accent-color-950` が、上に示したデフォルト（青）の値で `:root` に定義されています。上書きするのはこのレイヤーです。

2. **Tailwind テーマトークン** — パレットは Tailwind v4 のカラートークンにマッピングされます：

   ```css
   --color-hextra-accent-500: var(--color-accent-color-500);
   /* ...one line per shade... */
   ```

   Tailwind v4 は `--color-*` 変数からユーティリティクラスを派生させるため、これにより `hx:text-hextra-accent-600`、`hx:bg-hextra-accent-200`、`hx:border-hextra-accent-500` のようなクラスがテーマのテンプレート全体で利用できるようになります。

この間接化には意味があります。テンプレートは安定した `hextra-accent-*` トークンを参照し、ユーザーの上書きはその下にある `accent-color-*` レイヤーだけに触れます。

## アクセントカラーが適用される場所

このフォークでは、以前 HSL プライマリカラーを使っていたすべてのコンポーネントを移行しました：

| コンポーネント               | アクセントカラーの用途                                      |
| ---------------------------- | ----------------------------------------------------------- |
| タブ                         | 選択中タブのボーダーとテキスト、ホバー時の下線              |
| サイドバー                   | アクティブ項目のハイライト（ライト・ダークモード両方）      |
| 検索                         | 検索結果のハイライト、検索ボックスのフォーカスボーダー      |
| タグ                         | タグのボーダー                                              |
| カード                       | ホバー時のカードボーダー                                    |
| ヒーローボタン               | フォーカスリング                                            |
| テーマ切り替えと言語スイッチ | ホバー・アクティブ状態                                      |
| コードブロック               | コピーボタン、[行ハイライト](code-blocks#line-highlighting) |
| リンクとホームページ         | アクセントテキストと装飾                                    |

## シェードの使い分けの慣例

カスタムコンポーネントを作る際は、テーマと同じ慣例に従ってください：

- `50`〜`200` — 控えめな背景（ライトモードのハイライト、ホバー時の塗り）
- `300`〜`500` — ボーダー、リング、装飾
- `500`〜`600` — 「ブランド」シェード：リンクテキスト、選択状態
- `700`〜`950` — ダークモードの背景とボーダー（例：行ハイライトはダークモードで `950` を背景に、`500` をボーダーに使用）
