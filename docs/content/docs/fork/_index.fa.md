این فورک از [Hextra](https://github.com/imfing/hextra) مجموعه‌ای از ویژگی‌ها را بر روی پوسته اصلی اضافه می‌کند. این بخش هر آنچه مختص این فورک است، نحوه کارکرد داخلی هر ویژگی و روش پیکربندی آن را مستند می‌کند.

<!--more-->

## چه تفاوتی با نسخه اصلی دارد؟

| ویژگی          | نسخه اصلی                                                   | این فورک                                                                                      |
| -------------- | ----------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| تایپوگرافی     | مجموعه فونت سیستمی ثابت                                     | [فونت‌های Google](google-fonts) قابل پیکربندی برای سرفصل‌ها، متن اصلی و کد                    |
| رنگ پوسته      | یک رنگ اصلی HSL واحد (`--primary-hue/saturation/lightness`) | [پالت تأکیدی](accent-color) کامل ۱۱ سایه‌ای در `oklch`                                        |
| رنگ‌های خنثی   | پس‌زمینه‌های ساده `bg-white` / `#111`                       | [پالت‌های اختصاصی روشن و تاریک](color-palettes) ۱۱ سایه‌ای در `oklch`                         |
| بلوک‌های کد    | بدون حاشیه، `rounded-xl`، برجسته‌سازی کم‌رنگ                | [بلوک‌های حاشیه‌دار](code-blocks)، `rounded-sm`، برجسته‌سازی خط با رنگ تأکیدی، آیکون نوع فایل |
| وبلاگ          | فهرست تک‌ستونه                                              | [چیدمان سه‌ستونه](blog) با ستون هویت، کارت‌های نوشته، دکمه‌های اشتراک‌گذاری و ویجت‌ها         |
| فاوآیکون‌ها    | فایل‌های پراکنده در `static/`                               | سازمان‌یافته زیر `static/icons/` با پشتیبانی از [فاوآیکون حالت تاریک](favicons)               |
| گردش‌کار توسعه | فقط اسکریپت‌های npm                                         | [Makefile، devcontainer و ابزارهای همگام‌سازی با نسخه اصلی](dev-tooling)                      |
| نگارش محتوا    | برای یادآوری هر پارامتر باید مستندات را بخوانید             | [۸۹ اسنیپت VS Code](vscode-snippets) برای Shortcodeها، Front matter و بلوک‌های کد             |
