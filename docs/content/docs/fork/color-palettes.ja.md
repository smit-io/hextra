アップストリームの Hextra は背景をフラットに塗ります。ライトモードは `bg-white`、ダークモードは単一の `#111` で、それ以外には Tailwind の青みがかった `gray` と `slate` を使います。本フォークでは、すべての背景・ボーダー・テキストに **Tailwind の `neutral`** という無彩色の 1 系統だけを使います。

<!--more-->

## 1 つの系統で両モードを賄う

テーマ内のニュートラルはすべて `neutral-*` ユーティリティです。ライトモードでは低い段階、ダークモードでは高い段階を使い、要素上でペアにします。

```html
<div class="hx:bg-neutral-100 hx:dark:bg-neutral-900">…</div>
```

`neutral` は `gray` や `slate` と違い、青みを持たない真の無彩色です。これが最も効くのは本文テキストです。読者がページに滞在している間ずっと目に入るため、暖色系のアクセントと寒色系のグレーの組み合わせは、はっきりした違和感がなくてもちぐはぐに見えます。

## 段階

テーマはモードごとに 4 段階の背景を使い、ページに対する位置関係が常に予測できるように統一しています。

| 役割                                | ライト        | ダーク        |
| ----------------------------------- | ------------- | ------------- |
| ページ背景                          | `neutral-100` | `neutral-900` |
| 浮いた面 — コードブロック、カード   | `neutral-50`  | `neutral-950` |
| クローム — ファイル名バー、メニュー | `neutral-200` | `neutral-800` |
| ホバー・最前面                      | `neutral-200` | `neutral-800` |

方向がモードで反転する点に注意してください。ライトモードでは浮いた面はページより _明るく_、ダークモードでは _暗く_ なります。ボーダーは両モードとも逆向きで、ライトは `neutral-400`、ダークは `neutral-700`／`800` です。

## カスタマイズ

Tailwind v4 は自身のテーマカラーを CSS カスタムプロパティとして公開しているため、シェードの上書きは[アクセントカラー](accent-color)と同じ 1 行で済みます。テーマ本体のスタイルシートの後に読み込まれる `assets/css/custom.css` に書いてください。

```css {filename="assets/css/custom.css"}
:root {
  /* 少し暖かいページ背景 */
  --color-neutral-100: oklch(97.3% 0.005 85);

  /* わずかに青みのあるダーク背景 */
  --color-neutral-900: oklch(21% 0.01 250);
}
```

変更したいシェードだけを上書きすれば十分です。残りは Tailwind のデフォルトのままになります。

{{< callout type="warning" >}}
ランプの順序は保ってください。デフォルトと同じように、各シェードが隣より明るいか暗いかを維持します。コンポーネントはランプが単調であることを前提にしているため、順序を逆にするとボーダーが見えなくなったりテキストのコントラストが落ちたりします。
{{< /callout >}}

## なぜ独自ランプではなく `neutral` なのか

以前のフォークは `hextra-light-*`、`hextra-dark-*`、`hextra-white-*`、`hextra-black-*` という独自ランプ 4 系統を、`gray`・`slate`・`neutral` と並べて同梱していました。1 つの用途に 7 系統あり、どれを使うかの規則もなく、さらにモード別の 2 系統は番号の向きが逆でした（`hextra-light-100` はほぼ白、`hextra-dark-100` はほぼ黒）。

統合によって曖昧さがなくなり、同時に不具合も解消されました。ダークランプの `oklch` 明度値は変換ではなく `byte / 255` で算出されていたため、11 段階すべてが `#000000`–`#262626` の範囲に潰れ、最初の 4 段階は互いに 2 ポイント以内に収まっていました。`neutral` は全域にわたって十分な差を持ちます。

`hextra-accent-*` は影響を受けません。アクセントパレットは引き続きフォーク独自のものです。[アクセントカラー](accent-color)を参照してください。
