[アクセントカラー](accent-color)に加えて、このフォークはアップストリームのフラットな背景（ライトモードの `bg-white`、ダークモードの `#111`）を、専用の**ニュートラルパレット**に置き換えます。ライトモード用・ダークモード用にそれぞれ 11 段階のシェードを `oklch` で定義しています。

<!--more-->

## パレット

すべてのパレットは `assets/css/styles.css` にあり、Tailwind v4 のカラートークンとして公開されているため、テーマのどこでもユーティリティクラスとして使えます（`hx:bg-hextra-light-200`、`hx:dark:border-hextra-dark-900` など）。

### 追加のランプ — `hextra-white-*` と `hextra-black-*`

間隔の狭い `light`/`dark` ランプよりも高コントラストなニュートラルが必要な場合のために、フルレンジのグレースケールランプが 2 つ追加で定義されています（`#ffffff` → `#292929` と `#f6f6f6` → `#000000`）。

## 使用される場所

- **ページ背景** — `body` はライトモードで `hextra-light-100`、ダークモードで `hextra-dark-600` を使います（アップストリームの純白 / `#111` の代わりに）。ダークモードは意図的に純黒に*していません*。コンテンツのサーフェス（`hextra-dark-50` のコードブロック、`hextra-dark-700` のヘッダー）が、ページ背景よりはっきり手前や奥に見えるようにするためです。
- **コードブロック** — 背景、ボーダー、ファイル名ヘッダー。[コードブロック](code-blocks)を参照してください。
- **セクションボーダー** — 例：ダークモードの `h2` の下線ボーダーは `hextra-dark-900` を使います。
- **コンポーネントのクローム** — 検索、サイドバー、ステップ、アラート、ギャラリー、ナビバー、jupyter の各コンポーネントはすべて、`primary` ベースのグレーからパレットトークンに移行されました。
- **コールアウトとバッジ** — コールアウトと GitHub スタイルのアラートは、タイプ（info、warning、error など）ごとに GitHub にインスパイアされた彩度の高いパレットを使い、バッジは同じ考え方のより高コントラストなバリアントを使います。どちらも、1 つの色を不透明度違いで使い回すのではなく、ライトモードとダークモードで別々に調整されています。

## カスタマイズ

パレット変数はアクセントカラーと同じパターンに従います。`assets/css/custom.css` で上書きしてください：

```css {filename="assets/css/custom.css"}
:root {
  /* Warmer light background */
  --color-hextra-light-100: oklch(97.3% 0.005 85);

  /* Slightly blue-tinted dark background */
  --color-hextra-dark-600: oklch(17.6% 0.01 250);
}
```

変更したいシェードだけを上書きすれば、残りはデフォルトのままです。

{{< callout type="warning" >}}
ランプの*順序*は崩さないでください（デフォルトと同様に、各シェードが隣より暗い／明るい状態を保つこと）。コンポーネントはランプが単調であることを前提としているため、シェードを逆転させるとボーダーが見えなくなったり、テキストのコントラストが不足したりします。
{{< /callout >}}

## なぜ `oklch` なのか？

`oklch` は知覚的に均一な色空間です。明度チャンネルの等しいステップは目にも等しいステップに見えます。これは 16 進数や HSL では保証できません。グレースケールランプにおいては、`100` と `200` の間の視覚的な距離が `800` と `900` の間の距離と一致することを意味します。また、色付け（ティント）も簡単になります。どのシェードにも、明度を再調整することなく小さなクロマ値と色相を加えられます。参照用に、各シェードの 16 進数の等価値が `styles.css` のコメントに記載されています。
