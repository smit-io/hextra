نسخه اصلی Hextra رنگ اصلی خود را از سه متغیر HSL می‌گیرد (`--primary-hue`، `--primary-saturation`، `--primary-lightness`). این فورک آن را با یک **پالت تأکیدی ۱۱ سایه‌ای** واقعی تعریف‌شده در `oklch` جایگزین می‌کند که به شما کنترل کامل روی هر سایه می‌دهد، به جای آنکه همه سایه‌ها از یک فام واحد مشتق شوند.

<!--more-->

## چرا پالت به جای فام؟

مشتق کردن ۱۰ سایه از یک جفت فام/اشباع واحد، میان‌تُن‌های کدر و کنتراست ضعیف در دو انتهای طیف تولید می‌کند. یک پالت دست‌چین (یا ساخته‌شده با ابزار تولید پالت) اجازه می‌دهد هر سایه به‌طور مستقل تنظیم شود — و `oklch` روشنایی ادراکی را در فام‌های مختلف یکنواخت نگه می‌دارد، به‌طوری که یک رنگ تأکیدی نارنجی و یک رنگ تأکیدی آبی در سایه `500` به یک اندازه روشن *به نظر می‌رسند*.

## جایگزین کردن رنگ تأکیدی

یازده متغیر را به فایل `assets/css/custom.css` سایت خود اضافه کنید (Hextra این فایل را به‌طور خودکار بارگذاری می‌کند):

```css {filename="assets/css/custom.css"}
:root {
  --color-accent-color-50: oklch(0.977 0.013 236.62);
  --color-accent-color-100: oklch(0.951 0.026 236.824);
  --color-accent-color-200: oklch(0.901 0.058 230.902);
  --color-accent-color-300: oklch(0.828 0.111 230.318);
  --color-accent-color-400: oklch(0.746 0.16 232.661);
  --color-accent-color-500: oklch(0.685 0.169 237.323);
  --color-accent-color-600: oklch(0.588 0.158 241.966);
  --color-accent-color-700: oklch(0.5 0.134 242.749);
  --color-accent-color-800: oklch(0.443 0.11 240.79);
  --color-accent-color-900: oklch(0.391 0.09 240.876);
  --color-accent-color-950: oklch(0.293 0.066 243.157);
}
```

نیازی به بازسازی پوسته نیست — این‌ها متغیرهای CSS زمان اجرا هستند، بنابراین جایگزین کردن آن‌ها در `custom.css` همه عناصر دارای رنگ تأکیدی را یک‌جا بازآرایی می‌کند.

## ساخت پالت با UI Colors

روش پیشنهادی برای به دست آوردن مقادیر یازده سایه، [uicolors.app](https://uicolors.app) است — یک ابزار رایگان تولید پالت به سبک Tailwind:

{{% steps %}}

### رنگ برند خود را وارد کنید

به [uicolors.app](https://uicolors.app/create) بروید و رنگ پایه خود را در ورودی بالای صفحه تایپ یا جای‌گذاری کنید (hex، مثلاً `#0ea5e9`)، یا دکمه shuffle را بزنید تا گزینه‌ها را کاوش کنید. این ابزار رنگ شما را به عنوان سایه لنگر در نظر می‌گیرد و طیف کامل `50` تا `950` را حول آن می‌سازد.

### طیف را تنظیم دقیق کنید

پالت را روی کارت‌های نمونه رابط کاربری نمایش داده‌شده در صفحه پیش‌نمایش کنید. می‌توانید منحنی‌های فام، اشباع و روشنایی را تنظیم کنید تا سایه‌های میانی (`500`/`600`) با برند شما هم‌خوانی داشته باشند و دو انتهای طیف قابل استفاده بمانند (پس‌زمینه‌های روشن `50`/`100` و سطوح تاریک `900`/`950`).

### سایه‌ها را خروجی بگیرید

روی **Export** کلیک کنید و یک قالب سازگار با CSS انتخاب کنید. دو گزینه مستقیماً در اینجا کار می‌کنند:

- **Tailwind (OKLCH)** — با قالب بومی پوسته مطابقت دارد، گزینه ترجیحی
- **Tailwind (HEX)** — این هم مناسب است؛ هر مقدار رنگ معتبر CSS کار می‌کند

### مقادیر را در `custom.css` قرار دهید

هر سایه خروجی‌گرفته را در متغیر متناظر `--color-accent-color-*` کپی کنید — `50` به `50`، `100` به `100` و به همین ترتیب:

```css {filename="assets/css/custom.css"}
:root {
  /* "tangerine" palette from uicolors.app */
  --color-accent-color-50: oklch(0.98 0.016 73.684);
  --color-accent-color-100: oklch(0.954 0.038 75.164);
  --color-accent-color-200: oklch(0.901 0.076 70.697);
  --color-accent-color-300: oklch(0.837 0.128 66.29);
  --color-accent-color-400: oklch(0.75 0.183 55.934);
  --color-accent-color-500: oklch(0.705 0.213 47.604);
  --color-accent-color-600: oklch(0.646 0.222 41.116);
  --color-accent-color-700: oklch(0.553 0.195 38.402);
  --color-accent-color-800: oklch(0.47 0.157 37.304);
  --color-accent-color-900: oklch(0.408 0.123 38.172);
  --color-accent-color-950: oklch(0.266 0.079 36.259);
}
```

سایت را دوباره بارگذاری کنید — لینک‌ها، تب‌ها، برجسته‌سازی‌ها و همه عناصر تأکیدی دیگر بلافاصله پالت جدید را دریافت می‌کنند.

## نحوه کارکرد داخلی

دو لایه در `assets/css/styles.css`:

1. **پالت خام** — متغیرهای `--color-accent-color-50` … `--color-accent-color-950` روی `:root` با مقادیر پیش‌فرض (آبی) نشان داده‌شده در بالا تعریف شده‌اند. این همان لایه‌ای است که شما جایگزین می‌کنید.

2. **توکن‌های تم Tailwind** — پالت به توکن‌های رنگی Tailwind v4 نگاشت می‌شود:

   ```css
   --color-hextra-accent-500: var(--color-accent-color-500);
   /* ...one line per shade... */
   ```

   از آنجا که Tailwind v4 کلاس‌های کاربردی را از متغیرهای `--color-*` مشتق می‌کند، این کار کلاس‌هایی مانند `hx:text-hextra-accent-600`، `hx:bg-hextra-accent-200` و `hx:border-hextra-accent-500` را در سراسر قالب‌های پوسته در دسترس قرار می‌دهد.

این واسطه‌گری اهمیت دارد: قالب‌ها به توکن‌های پایدار `hextra-accent-*` ارجاع می‌دهند، در حالی که جایگزینی شما فقط لایه زیرین `accent-color-*` را لمس می‌کند.

## رنگ تأکیدی کجا اعمال می‌شود

این فورک همه اجزایی را که قبلاً از رنگ اصلی HSL استفاده می‌کردند مهاجرت داده است:

| جزء | کاربرد رنگ تأکیدی |
|---|---|
| تب‌ها | حاشیه و متن تب انتخاب‌شده؛ خط زیرین هنگام hover |
| نوار کناری | برجسته‌سازی مورد فعال (حالت روشن و تاریک) |
| جستجو | برجسته‌سازی نتیجه، حاشیه‌های فوکوس جعبه جستجو |
| تگ‌ها | حاشیه تگ‌ها |
| کارت‌ها | حاشیه کارت هنگام hover |
| دکمه Hero | حلقه فوکوس |
| کلید تغییر تم و زبان | حالت‌های hover/فعال |
| بلوک‌های کد | دکمه کپی، [برجسته‌سازی خط](code-blocks#line-highlighting) |
| لینک‌ها و صفحه اصلی | متن و تزئینات تأکیدی |

## قراردادهای استفاده از سایه‌ها

هنگام ساخت اجزای سفارشی، از همان قراردادهایی پیروی کنید که پوسته استفاده می‌کند:

- `50` تا `200` — پس‌زمینه‌های ملایم (برجسته‌سازی‌های حالت روشن، پرکننده‌های hover)
- `300` تا `500` — حاشیه‌ها، حلقه‌ها، تزئینات
- `500` تا `600` — سایه‌های «برند»: متن لینک، حالت‌های انتخاب‌شده
- `700` تا `950` — پس‌زمینه‌ها و حاشیه‌های حالت تاریک (مثلاً برجسته‌سازی خط در حالت تاریک از `950` به عنوان پس‌زمینه با حاشیه `500` استفاده می‌کند)
