فراتر از [رنگ تأکیدی](accent-color)، این فورک پس‌زمینه‌های ساده نسخه اصلی (`bg-white` در حالت روشن، `#111` در حالت تاریک) را با **پالت‌های خنثی** اختصاصی جایگزین می‌کند — یازده سایه برای هر یک از حالت‌های روشن و تاریک، تعریف‌شده در `oklch`.

<!--more-->

## پالت‌ها

همه پالت‌ها در `assets/css/styles.css` قرار دارند و به‌صورت توکن‌های رنگی Tailwind v4 در دسترس‌اند، بنابراین می‌توان از آن‌ها به‌صورت کلاس‌های کاربردی در هر جای پوسته استفاده کرد (`hx:bg-hextra-light-200`، `hx:dark:border-hextra-dark-900`، …).

### حالت روشن — `hextra-light-*`

یک طیف خاکستری فشرده از نزدیک به سفید تا خاکستری میانی:

| توکن              | مقدار              | Hex       |
| ------------------ | ------------------ | --------- |
| `hextra-light-50`  | `oklch(98.8% 0 0)` | `#fcfcfc` |
| `hextra-light-100` | `oklch(97.3% 0 0)` | `#f8f8f8` |
| `hextra-light-200` | `oklch(93.7% 0 0)` | `#efefef` |
| `hextra-light-300` | `oklch(90.6% 0 0)` | `#e7e7e7` |
| `hextra-light-400` | `oklch(87.1% 0 0)` | `#dedede` |
| `hextra-light-500` | `oklch(83.5% 0 0)` | `#d5d5d5` |
| `hextra-light-600` | `oklch(80.4% 0 0)` | `#cdcdcd` |
| `hextra-light-700` | `oklch(76.9% 0 0)` | `#c4c4c4` |
| `hextra-light-800` | `oklch(73.3% 0 0)` | `#bbbbbb` |

### طیف‌های اضافی — `hextra-white-*` و `hextra-black-*`

دو طیف خاکستری تمام‌دامنه اضافی (`#ffffff` → `#292929` و `#f6f6f6` → `#000000`) برای مواردی تعریف شده‌اند که به خنثی‌هایی با کنتراست بالاتر از طیف‌های فشرده `light`/`dark` نیاز دارید.

## کجا استفاده می‌شوند

- **پس‌زمینه صفحه** — عنصر `body` در حالت روشن از `hextra-light-100` و در حالت تاریک از `hextra-dark-600` استفاده می‌کند (به جای سفید خالص / `#111` نسخه اصلی). حالت تاریک عمداً سیاه خالص _نیست_: سطوح محتوا (بلوک‌های کد در `hextra-dark-50`، سربرگ‌ها در `hextra-dark-700`) به‌طور محسوس بالاتر یا پایین‌تر از پس‌زمینه صفحه قرار می‌گیرند.
- **بلوک‌های کد** — پس‌زمینه‌ها، حاشیه‌ها و سربرگ‌های نام فایل؛ [بلوک‌های کد](code-blocks) را ببینید.
- **حاشیه‌های بخش‌ها** — مثلاً خط زیرین `h2` در حالت تاریک از `hextra-dark-900` استفاده می‌کند.
- **قاب اجزا** — اجزای جستجو، نوار کناری، مراحل، هشدارها، گالری، نوار ناوبری و jupyter همگی از خاکستری‌های مبتنی بر `primary` به توکن‌های پالت مهاجرت داده شده‌اند.
- **کال‌اوت‌ها و نشان‌ها** — کال‌اوت‌ها و هشدارهای به سبک GitHub برای هر نوع (info، warning، error و ...) از یک پالت اشباع‌شده و الهام‌گرفته از GitHub استفاده می‌کنند و نشان‌ها گونه‌ای با کنتراست بالاتر از همان ایده هستند. هر دو به جای استفاده مجدد از یک ته‌رنگ با شفافیت‌های مختلف، جداگانه برای حالت روشن و تاریک تنظیم شده‌اند.

## سفارشی‌سازی

متغیرهای پالت از همان الگوی رنگ تأکیدی پیروی می‌کنند — آن‌ها را در `assets/css/custom.css` جایگزین کنید:

```css {filename="assets/css/custom.css"}
:root {
  /* Warmer light background */
  --color-hextra-light-100: oklch(97.3% 0.005 85);

  /* Slightly blue-tinted dark background */
  --color-hextra-dark-600: oklch(17.6% 0.01 250);
}
```

فقط لازم است سایه‌هایی را جایگزین کنید که می‌خواهید تغییر دهید؛ بقیه مقادیر پیش‌فرض خود را حفظ می‌کنند.

{{< callout type="warning" >}}
_ترتیب_ طیف را دست‌نخورده نگه دارید (هر سایه مانند پیش‌فرض‌ها تیره‌تر/روشن‌تر از همسایه خود باشد). اجزا فرض می‌کنند که طیف یکنواخت است — وارونه کردن سایه‌ها به حاشیه‌های نامرئی یا متن کم‌کنتراست منجر می‌شود.
{{< /callout >}}

## چرا `oklch`؟

`oklch` یک فضای رنگی یکنواخت ادراکی است: گام‌های برابر در کانال روشنایی برای چشم هم گام‌های برابر به نظر می‌رسند، چیزی که hex/HSL نمی‌توانند تضمین کنند. برای طیف‌های خاکستری این یعنی فاصله بصری بین `100` و `200` با فاصله بین `800` و `900` برابر است. همچنین ته‌رنگ دادن را ساده می‌کند — می‌توانید مقدار کوچکی chroma و یک فام به هر سایه اضافه کنید بدون آنکه روشنایی آن نیاز به تنظیم مجدد داشته باشد. معادل hex هر سایه برای مرجع در یک کامنت در `styles.css` آمده است.
