{{/* Cover image for a post card or a post hero. Renders nothing when the page has no cover, so there is no placeholder and no layout shift. The image is decorative — the post title always sits next to it — so `alt` is intentionally empty. When the resolver returns an `lqip`, it is handed to the stylesheet as `--hextra-lqip` and painted as the image's own background, so a blurred stand-in shows until the real pixels land on top of it. Covers without one (remote URLs, SVGs) simply fall back to the flat column background. @param {page} page The post. @param {string} [variant] "card" (default) or "hero". @example {{ partial "blog/cover.html" (dict "page" . "variant" "hero") }} */}} {{- $hero := eq (.variant | default "card") "hero" -}} {{- $process := cond $hero "Resize 1600x webp q80" "Resize 800x webp q80" -}} {{- $cover := partial "utils/page-image.html" (dict "page" .page "process" $process) -}} {{- with $cover.url -}} {{- $lazyLoading := site.Params.enableImageLazyLoading | default true -}} {{- end -}}
