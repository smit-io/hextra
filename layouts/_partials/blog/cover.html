{{/* Cover for a post card or a post hero. Renders nothing when the page has no cover, so there is no placeholder and no layout shift. The image is decorative — the post title always sits next to it — so `alt` is intentionally empty. A post can put a command there instead of a picture by setting `coverText`, in which case none of the image machinery below runs: there is no file to resolve, process or measure. When the resolver returns an `lqip`, it is handed to the stylesheet as `--hextra-lqip` and painted as the image's own background, so a blurred stand-in shows until the real pixels land on top of it. Covers without one (remote URLs, SVGs) simply fall back to the flat column background. Callers reach this through `partialCached`, keyed on the post's RelPermalink and the variant: the output depends on nothing else, and a list page renders the same post's card on /blog/, its tag pages and its series page. A `coverText` post is the expensive case - each line is a separate `highlight` call. @param {page} page The post. @param {string} [variant] "card" (default) or "hero". @example {{ partial "blog/cover.html" (dict "page" . "variant" "hero") }} */}} {{- $hero := eq (.variant | default "card") "hero" -}} {{- with .page.Params.coverText -}} {{- partial "components/command-block.html" (dict "lines" . "mode" "cover" "class" (cond $hero "hextra-command--hero" "")) -}} {{- else -}} {{- $process := cond $hero "Resize 1600x webp q80" "Resize 800x webp q80" -}} {{- $cover := partial "utils/page-image.html" (dict "page" .page "process" $process) -}} {{- with $cover.url -}} {{- $lazyLoading := site.Params.enableImageLazyLoading | default true -}} {{- end -}} {{- end -}}
