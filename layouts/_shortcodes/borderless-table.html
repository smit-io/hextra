Markdown tables elsewhere on the page are untouched. Below the `lg` breakpoint the header row is dropped and each cell becomes its own line, so a four-column reference reads as a stack rather than scrolling sideways. Put the identifying column first: it is what the reader sees at the top of each stacked group.
